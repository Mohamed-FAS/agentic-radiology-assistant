## Website upload steps

1. Create a new GitHub repository named `agentic-radiology-assistant`.
2. Choose **Public** if you want recruiters to see it.
3. Do not initialise it with another README or `.gitignore`.
4. Choose **uploading an existing file**.
5. Upload the contents of this package while preserving the `notebooks`, `assets`, and `results` folders.
6. Commit with: `Add Agentic Radiology Assistant portfolio project`.
7. Add the suggested topics in the repository **About** section.

Before committing future notebook versions, make sure notebook outputs do not contain API keys or temporary Gradio share URLs.
